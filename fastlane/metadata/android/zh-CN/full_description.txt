Restoid 是一款现代、注重隐私的 Android 备份解决方案，由强大、开源的 restic 引擎驱动。借助企业级加密和闪电般、节省空间的去重功能，确保您的应用、数据、照片和文档安全无虞。

无论您是想将照片备份到家用 NAS，在云端存储加密快照，还是在已获取 root 权限的设备上保留完整的应用数据，Restoid 都能让您完全掌控，且无任何追踪器、广告或专有绑定。

Root 权限完全可选：无需 root 即可备份自定义文件夹、照片和文档；仅在备份私有应用数据时需要 root 权限。

主要功能：

极速且支持去重
• 内容定义去重：仅上传独特的已更改块，使后续备份速度极快，且比传统的 tar.gz 压缩包效率高得多。
• 节省空间：多个快照共享公共数据，使存储占用保持在最低限度。

零知识加密
• 企业级安全：所有快照都使用最先进的密码学通过 restic 进行加密。
• 您的密码和加密密钥完全由您掌控。

灵活的存储后端
• 本地存储：保存到内部存储、SD 卡或 USB OTG 驱动器。
• 网络与云：原生支持 SFTP（SSH 密钥和密码）、REST 服务器以及兼容 Amazon S3 的对象存储（Garage、MinIO、Wasabi、Cloudflare R2、Backblaze B2）。

完整应用与数据备份（需要 Root）
• 选择性备份已安装的用户应用程序。
• 精细控制：选择是否包含 APK、应用数据、设备保护数据、外部文件或 OBB 缓存。

自定义文件与媒体
• 备份个人文件夹：DCIM、文档、下载或设备上的任何目录。

自动化后台计划
• 配置循环计划（每日、每周或自定义间隔）。
• 智能触发条件：仅在充电时、连接不计费 Wi-Fi 时或满足电池条件时运行。

精准且安全的恢复
• 恢复整个应用或特定部分（例如恢复数据而不覆盖已安装的 APK）。
• 降级保护可防止意外将旧版本应用覆盖恢复到新版本上。

零厂商绑定
• 标准 restic 格式：存储库使用原生的、开源的 restic 格式。您随时可以使用官方 restic CLI 在任何 PC（Linux、macOS、Windows）上访问、检查、挂载或恢复您的数据——即使没有手机也行。

维护与存储库运行状况
• 通过自动快照保留策略（按天、周、月清理旧备份）保持存储库紧凑。
• 一键运行存储库完整性检查并清除陈旧锁。

现代 Material 3 Expressive UI
• 采用现代 Jetpack Compose 和 Material 3 Expressive 设计构建，具有动态主题、流畅动画和边到边布局。
• 100% 免费且开源（GPLv3），零分析、零遥测或第三方追踪。
