Restoid 是一款现代、注重隐私的 Android 备份解决方案，由强大、开源的 restic 引擎驱动。通过企业级加密以及闪电般快速、节省空间的去重技术，确保您的应用、数据、联系人、通话记录、照片和文档的安全。

无论您是想将照片备份到家用 NAS，在云端存储加密快照，还是在已获取 root 权限的设备上保留完整的应用数据，Restoid 都能让您完全掌控，且无任何追踪器、广告或专有绑定。

Root 权限完全可选：无需 root 即可备份自定义文件夹、照片、文档、联系人和通话记录；仅在备份私有应用数据时才需要 root 权限。

主要功能：

极速且支持去重
• 内容定义去重：仅上传独特的已更改块，使后续备份速度极快，且比传统的 tar.gz 压缩包效率高得多。
• 节省空间：多个快照共享公共数据，使存储占用保持在最低限度。

零知识加密
• 企业级安全：所有快照都使用最先进的密码学通过 restic 进行加密。
• 您的密码和加密密钥完全由您掌控。

灵活的存储后端
• 本地存储：保存到内部存储、SD 卡或 USB OTG 驱动器。
• 原生网络后端：直接支持 SFTP（SSH 密钥和密码）、REST 服务器以及兼容 Amazon S3 的对象存储（Garage、MinIO、Wasabi、Cloudflare R2、Backblaze B2）。
• 通过 Rclone 实现云端与额外后端：内置 rclone 支持，通过导入或粘贴 rclone.conf，即可连接数十家存储提供商和协议（如 Google Drive、OneDrive、Dropbox、WebDAV、Nextcloud、pCloud 等）。

完整应用与数据备份（需要 Root）
• 选择性备份已安装的用户应用程序。
• Granular control: Choose whether to include APKs, app data, device-protected data, external files, or OBB caches, and exclude specific paths inside app data (such as large caches or re-downloadable media) while preserving core databases and settings.

自定义文件与媒体
• 备份个人文件夹：DCIM、文档、下载或设备上的任何目录。

联系人与通话记录
• 无需 root 即可备份和恢复您的联系人（包括群组和照片）以及通话记录；备份可以手动运行或按自动计划运行。

自动化后台计划
• 配置循环计划（每日、每周或自定义间隔）。
• 智能触发条件：仅在充电时、连接不计费 Wi-Fi 时或满足电池条件时运行。

精准且安全的恢复
• 恢复整个应用或特定部分（例如恢复数据（不覆盖已安装的 APK）、自定义目录、联系人和通话记录。
• 降级保护可防止意外将旧版本应用覆盖恢复到新版本上。

零厂商绑定
• 标准 restic 格式：存储库使用原生的、开源的 restic 格式。您随时可以使用官方 restic CLI 在任何 PC（Linux、macOS、Windows）上访问、检查、挂载或恢复您的数据——即使没有手机也行。

维护与存储库运行状况
• 通过自动快照保留策略（按天、周、月清理旧备份）保持存储库紧凑。
• 一键运行存储库完整性检查并清除陈旧锁。

现代 Material 3 Expressive UI
• 采用现代 Jetpack Compose 和 Material 3 Expressive 设计构建，具有动态主题、流畅动画和边到边布局。
• 100% 免费且开源（GPLv3），零分析、零遥测或第三方追踪。
